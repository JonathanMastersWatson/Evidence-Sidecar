# Primitive Boundary

CVS defines evidence formation at the execution boundary.

It does not define:

- constraint behaviour
- system architecture
- orchestration
- deployment models
- implementation patterns

Any system built using CVS as a primitive is a derivative implementation.

Responsibility for design, deployment, and operation of that derivative
remains entirely with the implementing party.

---

*This file defines the boundary of the CVS primitive. It does not
modify the canonical CVS specification, the Evidence Object model,
or the conformance requirements defined in `CONFORMANCE.md`.*
